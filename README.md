# 📚 Polkan - Каталог сказок

Современное веб-приложение для чтения и прослушивания сказок с удобной админ-панелью для управления контентом.

## ✨ Особенности

- 🎵 **Аудио-плеер** - встроенный плеер с сохранением прогресса
- 📖 **Чтение сказок** - удобный интерфейс для чтения
- 📥 **Скачивание** - возможность скачать аудио и тексты
- 👨‍💼 **Админ-панель** - управление сказками, загрузка файлов
- 💾 **Автосохранение** - все данные сохраняются в localStorage
- 📱 **Адаптивный дизайн** - работает на всех устройствах

## 🚀 Быстрый старт

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/stepanboost/polkan.git
cd polkan/orangery-ventures-harmony-4155

# Установите зависимости
npm install

# Запустите приложение
npm run dev
```

### Доступ к приложению

- **Главная страница**: http://localhost:8082
- **Админ-панель**: http://localhost:8082/admin
  - Логин: `admin`
  - Пароль: `admin`

## 🎯 Функциональность

### Для пользователей
- Просмотр каталога сказок
- Чтение текстов сказок
- Прослушивание аудиоверсий
- Скачивание файлов
- Поиск по названию и автору

### Для администраторов
- Добавление новых сказок
- Загрузка аудиофайлов и изображений
- Редактирование существующих сказок
- Управление контентом
- Просмотр статистики

## 🛠️ Технологии

- **Frontend**: React 18, TypeScript
- **UI**: Tailwind CSS, shadcn/ui
- **Роутинг**: React Router
- **Состояние**: React Context API
- **Сборка**: Vite
- **Хранение**: localStorage (для демо)

## 💾 Хранение данных

Приложение использует localStorage для демонстрации функциональности:
- Сказки сохраняются в `localStorage['fairyTales']`
- Состояние аудио в `localStorage['audioState']`
- Загруженные файлы в `localStorage['audio_*']` и `localStorage['image_*']`
