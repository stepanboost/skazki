🧪 Тест функций админ-панели

1. Тест загрузки аудиофайлов

Проверяем, что аудиофайлы правильно сохраняются в localStorage

Перетащите аудиофайл сюда или выберите файл

Выберите аудиофайл для тестирования

2. Тест загрузки изображений

Проверяем, что изображения правильно сохраняются в localStorage

Перетащите изображение сюда или выберите файл

Выберите изображение для тестирования

3. Тест воспроизведения загруженного аудио

Проверяем, что загруженные аудиофайлы можно воспроизводить


Сначала загрузите аудиофайл

4. Тест скачивания загруженных файлов

Проверяем, что загруженные файлы можно скачать

Нажмите кнопку для тестирования

5. Проверка localStorage

Проверяем содержимое localStorage

Нажмите кнопку для проверки

6. Инструкции для полного тестирования

Для полного тестирования админ-панели:

  1. Откройте основное приложение по адресу http://localhost:8082
  2. Перейдите в админ-панель: http://localhost:8082/admin
  3. Войдите в админку (логин: admin, пароль: admin)
  4. Нажмите "Добавить новую сказку"
  5. Заполните форму и загрузите аудиофайл и изображение
  6. Сохраните сказку
  7. Перейдите на главную страницу и проверьте, что сказка отображается
  8. Попробуйте воспроизвести аудио и скачать файл
  9. Обновите страницу и проверьте, что все работает после перезагрузки
