1) Цель проекта

Дать пользователю удобный каталог сказок в одной вертикальной ленте: можно читать текст, слушать аудио и скачивать файлы. В админ-панели редактор может добавлять и удалять сказки (текст + аудио + обложка).

2) Роли

Гость/Пользователь: просматривает ленту сказок, открывает сказку, слушает, скачивает.

Администратор: авторизуется в админке, загружает/редактирует/удаляет сказки и связанные файлы.

3) Пользовательские сценарии

Список сказок: открываю главную → вижу вертикальную колонку карточек (обложка, название, краткое описание/первые строки, длительность аудио, кнопки “Читать”, “Слушать”, “Скачать”).

Чтение: нажимаю “Читать” → отдельная страница сказки: заголовок, обложка, текст в одну колонку (адаптивный кегль), аудио-плеер.

Прослушивание: на карточке или на странице сказки — HTML5-плеер (play/pause, прогресс, перемотка).

Скачивание: на карточке и на странице сказки кнопка “Скачать” (минимум: .mp3, .pdf; опционально .txt/.epub).

Поиск/фильтр (MVP — опционально): строка поиска по названию/автору/тегам.

404/пустые состояния: понятные экраны при отсутствии контента.

4) Функциональные требования
4.1. Витрина (публичная часть)

Вертикальная лента карточек сказок (lazy-load, пагинация или “Загрузить ещё”).

Карточка: обложка (1:1 или 3:4), название, автор (если есть), теги (опц.), оценочная длительность аудио (мин.), кнопки:

“Читать” → страница сказки.

“Слушать” → встроенный плеер (можно открыть мини-плеер в карточке).

“Скачать” → выпадающее меню форматов (mp3, pdf).

Страница сказки:

Заголовок, обложка, метаданные (автор, длительность, теги).

Текст в одной колонке (адаптивная типографика, тёмная тема переключателем — опц.).

Аудио-плеер (HTML5). При наличии нескольких озвучек — список дорожек.

Кнопки “Скачать .mp3”, “Скачать .pdf”.

SEO-разметка (schema.org/Article) + Open Graph.

4.2. Админ-панель

Авторизация: логин/пароль (минимум), защита от brute-force, сессии/refresh-токены.

Список сказок (таблица): поиск, сортировка по дате/названию, статусы (черновик/опубликовано).

Форма создания/редактирования сказки:

Поля: Заголовок (обяз.), Слаг (авто), Автор (опц.), Краткое описание (опц.), Текст (обяз., Markdown или Rich-text), Теги (опц.), Порядок сортировки (опц.), Статус (черновик/опубликовано).

Загрузка обложки (jpg/png/webp, макс размер, авто-ресайз).

Загрузка аудио (mp3/m4a; лимит размера; сервер пересчитает длительность).

Кнопки: “Сохранить черновик”, “Опубликовать”, “Удалить”.

Удаление сказки: мягкое (soft-delete) с возможностью восстановления (опц.) или жёсткое — по решению (для MVP можно жёсткое).

Управление файлами: просмотр и удаление прикреплённых аудио/обложек (с предупреждением).

Логи действий (опц.): кто что загрузил/удалил.

4.3. Загрузка/хранение файлов

Хранилище: объектное (например, S3-совместимое) или локально (для дев/стейджа).

При загрузке:

Валидация типа/размера.

Генерация уникального имени и путей.

Создание превью/ресайз обложки (например, 600px и 1200px по ширине).

Извлечение длительности аудио.

Публичные URL для обложек/аудио с корректными заголовками кеширования (Cache-Control).

4.4. Скачивание

Сервировать с правильными заголовками:

Content-Disposition: attachment; filename="skazka-title.mp3/pdf"

Content-Type по формату.

PDF из текста генерируется на сервере при запросе или при публикации (кешировать).

4.5. Безопасность

Админка за /admin с обязательной аутентификацией.

Защита загрузок (только администратор).

Проверка и очистка HTML/Markdown (XSS-safe рендер).

CORS/CSRF защита (если SSR + формы — встроенные механизмы).

Rate limit на публичные API (скачивание/поиск).
